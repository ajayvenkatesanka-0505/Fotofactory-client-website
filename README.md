# 📸 The Foto Factory - Cinematic Studio Website

A high-end, dark-mode cinematic portfolio and booking platform designed and developed for a professional photography and videography studio.

## ✨ Key Features
- **Cinematic Dark UI:** Built with custom styling and immersive smooth scrolling effects.
- **Interactive Gallery:** Showcases Wedding, Portrait, Commercial, and Maternity portfolios.
- **Dynamic Rate Estimator:** Allows clients to calculate custom package pricing based on their specific event requirements.
- **Direct WhatsApp Booking:** Seamless CTA integration for instant client inquiries and bookings.

## 🛠️ Tech Stack
- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- **Tailwind CSS / Custom Styling**
